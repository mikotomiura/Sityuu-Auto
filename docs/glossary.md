# ユビキタス言語定義（glossary.md）

本ドキュメントは、プロジェクト内で使用する用語の定義を統一し、チーム（人間・AI含む）間のコミュニケーション齟齬を防ぐためのものである。

---

## ドメイン用語（占い・鑑定領域）

| 用語 | 英語表記 | 定義 |
|------|----------|------|
| 命式 | Meishiki / NatalChart | 四柱推命・算命学において、生年月日・出生時間から算出される個人の運命的特性を表す構造化データ。年柱・月柱・日柱・時柱の干支で構成される |
| 四柱推命 | ShichuSuimei | 生年月日時を「年柱・月柱・日柱・時柱」の4つの柱として干支に変換し、運勢や性格を読み解く東洋占術 |
| 算命学 | SanmeiGaku | 中国発祥の運命学。四柱推命と類似するが、独自の星体系（十大主星・十二大従星）を持つ |
| 干支 | KanShi / GanZhi | 十干（甲乙丙丁…）と十二支（子丑寅卯…）の組み合わせ。六十干支で一巡する |
| 十干 | Jikkan | 甲・乙・丙・丁・戊・己・庚・辛・壬・癸 の10種。五行（木火土金水）×陰陽で構成 |
| 十二支 | Junishi | 子・丑・寅・卯・辰・巳・午・未・申・酉・戌・亥 の12種 |
| 日干 | Nikkan | 日柱の天干。命式において最も重要な要素で、本人の本質を表す |
| 年柱 | NenChu | 生まれた年から算出される干支の柱。先祖・社会との関係を示す |
| 月柱 | GetsuChu | 生まれた月から算出される干支の柱。両親・仕事運を示す |
| 日柱 | NitChu | 生まれた日から算出される干支の柱。本人の本質を示す |
| 時柱 | JiChu | 生まれた時間から算出される干支の柱。晩年・子孫運を示す |
| 天中殺 | Tenchusatsu | 算命学における空亡期間。特定の干支の組み合わせで決定される、注意すべき時期 |
| 十大主星 | JudaiShusei | 算命学の星体系。貫索星・石門星・鳳閣星・調舒星・禄存星・司禄星・車騎星・牽牛星・龍高星・玉堂星 |
| 十二大従星 | JuniDaiJusei | 算命学における人体星図に配置される12種の星。エネルギーの強弱を表す |
| 五行 | GoGyo | 木・火・土・金・水の5つの元素。相生・相剋の関係を持つ |
| 鑑定 | Kantei / Reading | 命式を基に相談者の性格・運勢・適性等を読み解き、助言を行う行為 |
| 鑑定テキスト | ReadingText | AI が生成する鑑定のベース文章。出品者が加筆・編集して最終鑑定文を完成させる |

## ビジネスドメイン用語

| 用語 | 英語表記 | 定義 |
|------|----------|------|
| 出品者 | Seller / Mentor | 本システムの利用者。相談者に対し占い・メンタリングサービスを提供する人物 |
| 相談者 | Client / Consultee | 出品者のサービスを受ける人物。生年月日等の個人情報を提供する |
| メンタリング | Mentoring | 出品者が相談者に対して行う傾聴・助言活動。占い結果を踏まえて行われる |
| セッション | Session | 出品者と相談者の1回のやり取り（通話・チャット等）の単位 |
| 鑑定履歴 | ReadingHistory | 過去に行った鑑定の記録。相談者ごとにSQLiteに保存される |
| 傾聴のヒント | ListeningHint | AIが命式と悩みから生成する、出品者がメンタリング時に参考にするための指針テキスト |

## 技術ドメイン用語

| 用語 | 英語表記 | 定義 |
|------|----------|------|
| ローカルファースト | LocalFirst | データとアプリケーションをローカルPC上で完結させるアーキテクチャ方針 |
| 命式計算エンジン | FortuneEngine | `lunar_python` を中核とし、干支・星の算出ロジックを提供するモジュール |
| プロンプトテンプレート | PromptTemplate | LLM API に送信する定型プロンプトの雛形。命式データと悩みを埋め込む変数を含む |
| UI層 | UILayer | Streamlit で構築されたフロントエンド。データ入力・結果表示を担当 |
| ロジック層 | LogicLayer | 命式算出・データ変換等のビジネスロジックを担当するモジュール群 |
| AI連携層 | AILayer | LLM API との通信・プロンプト構築・レスポンス解析を担当するモジュール |
| DB層 | DBLayer | SQLite を用いたデータ永続化を担当するモジュール |

## システム内部の状態・概念

| 用語 | 定義 |
|------|------|
| 命式表 | 算出された命式データを表形式に整形したもの。UI に表示される |
| 鑑定レポート | 命式表 + AIが生成した鑑定テキスト + 傾聴のヒントをまとめた出力物 |
| セッションデータ | 1回の鑑定作業で生成されるすべてのデータ（入力・命式・AI出力・メモ）の総称 |

## 命名規則との対応

コード内の命名は、本ドキュメントの英語表記に準拠すること。

```python
# Good
class NatalChart:       # 命式
    day_stem: str       # 日干
    year_pillar: Pillar # 年柱

class Client:           # 相談者
    birth_date: date    # 生年月日

class ReadingHistory:   # 鑑定履歴
    session_id: str     # セッションID

# Bad
class Uranai:           # ドメイン用語の日本語ローマ字は避ける
class Data:             # 抽象的すぎる
class Info:             # 何の情報か不明
```
