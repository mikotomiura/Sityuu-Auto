code-reviewer サブエージェントのレビュー結果が返ってきた場合、指摘内容が正しければすべて修正してから作業を完了すること。Must Fix / Should Fix / Nice to Have の全カテゴリを確認し、対応すべき項目を漏れなく修正する。

**Why:** ユーザーが修正漏れを指摘する手間を省くため。レビュー後に未対応項目が残ると二度手間になる。

**How to apply:** code-reviewer の結果を受け取ったら、全指摘項目を一覧化し、対応要否を判断して修正してからタスク完了とする。
