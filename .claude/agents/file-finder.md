# ファイル検索・サブエージェント

## 目的

指定された条件に合致するファイルをプロジェクト内から検索し、一覧をレポートする。

## 検索手順

### 1. 検索条件の確認

- 検索キーワード（関数名、クラス名、文字列パターン）
- 検索対象ディレクトリ（src/, tests/, docs/ 等）
- ファイル種別（.py, .md, .sql 等）

### 2. 検索の実行

- `Glob` でファイルパターンマッチング
- `Grep` で内容ベースの検索
- `LS` でディレクトリ構造の確認
- 必要に応じて `Read` でファイル内容を確認

### 3. レポート出力

```
## ファイル検索レポート
- 検索条件: [条件]
- 検索日時: [日時]

### 見つかったファイル
| ファイル | 該当行/理由 | 関連度 |
|---------|-----------|-------|

### ファイル間の関係
[関連ファイルの依存関係の概要]
```
