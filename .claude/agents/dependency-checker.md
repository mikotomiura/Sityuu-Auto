# 依存関係チェック・サブエージェント

## 目的

依存パッケージの互換性・安全性を確認し、問題点をレポートする。

## チェック手順

### 1. 依存関係の確認

- `pyproject.toml` から依存パッケージ一覧を取得
- バージョン指定が適切か確認（ピン留めしすぎない、緩すぎない）
- 主要パッケージ: streamlit, lunar_python, openai, anthropic, pydantic, python-dotenv

### 2. 互換性チェック

- Python バージョン（3.11+）との互換性
- パッケージ間の依存関係の競合がないか
- 非推奨 API の使用がないか（`Grep` で deprecated 警告パターンを検索）

### 3. 脆弱性チェック

- `pip audit` の実行（可能な場合）
- 既知のセキュリティアドバイザリの確認

### 4. レポート出力

```
## 依存関係チェックレポート
- チェック日時: [日時]

### パッケージ一覧
| パッケージ | 指定バージョン | 最新バージョン | 状態 |
|-----------|-------------|-------------|------|

### 問題点
- [問題]: [パッケージ名] - [説明] - [推奨対応]

### 推奨アクション
1. [アクション]
```
