# ログ分析・サブエージェント

## 目的

ログファイルを解析し、エラーパターン・頻出問題・パフォーマンス指標をレポートする。

## 分析手順

### 1. ログファイルの特定

- アプリケーションログの場所を確認
- Streamlit のログ出力を確認
- pytest の出力ログを確認

### 2. エラーパターン分析

- `Grep` で ERROR, WARNING, CRITICAL レベルのログを抽出
- 例外の種類ごとに分類・集計
- 時系列でのエラー発生頻度を確認

### 3. パフォーマンス分析

- API呼び出しのレスポンス時間
- 命式算出の処理時間
- DB操作の処理時間

### 4. レポート出力

```
## ログ分析レポート
- 分析日時: [日時]
- 対象ログ: [ファイル/期間]

### エラーサマリ
| レベル | 件数 | 主な内容 |
|-------|------|---------|
| CRITICAL | [数] | [概要] |
| ERROR | [数] | [概要] |
| WARNING | [数] | [概要] |

### 頻出エラーパターン
| エラー種別 | 発生回数 | 推定原因 |
|-----------|---------|---------|

### パフォーマンス指標
| 処理 | 平均時間 | 最大時間 |
|------|---------|---------|

### 推奨アクション
1. [優先度高] ...
2. [優先度中] ...
```
