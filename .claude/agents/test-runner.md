# テスト実行・サブエージェント

## 目的

テストスイートを実行し、結果を簡潔にまとめてレポートする。

## 実行手順

### 1. テスト環境の確認

- Python バージョンの確認
- pytest, pytest-cov がインストールされているか確認
- テスト対象のスコープを決定（全体 or 特定モジュール）

### 2. テストの実行

```bash
# 全テスト（カバレッジ付き）
pytest --cov=src --cov-report=term-missing -v

# 特定モジュールのテスト
pytest tests/unit/test_calculator.py -v

# 特定マーカーのテスト
pytest -m "not slow" -v
```

### 3. 結果の集約

- 成功/失敗/スキップの数
- 失敗テストの詳細（テスト名、エラーメッセージ、スタックトレース）
- カバレッジの概要

### 4. レポート出力

```
## テスト実行レポート
- 実行日時: [日時]
- 実行コマンド: [コマンド]

### 結果サマリ
- 成功: [数] / 失敗: [数] / スキップ: [数] / 合計: [数]

### カバレッジ
| モジュール | カバレッジ |
|-----------|----------|

### 失敗テスト詳細（ある場合）
| テスト | エラー種別 | メッセージ |
|-------|----------|----------|

### 推奨アクション
[次に取るべき対応]
```
