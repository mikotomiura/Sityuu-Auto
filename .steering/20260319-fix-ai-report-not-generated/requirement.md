# 要件定義: AI鑑定レポート生成ボタンが動作しないバグの修正
- 日付: 2026-03-19
- 関連Issue/PR: なし

## 目的
「AI鑑定レポートを生成」ボタンを押しても何も出力されないバグを修正する。

## 症状
1. 相談者情報を入力し「命式を算出して鑑定を開始」を押下 → 命式が算出される（正常）
2. 「AI鑑定レポートを生成」を押下 → 何も出力されない（バグ）

## 根本原因
Streamlitの再実行モデルに起因するボタン到達不能問題。

「AI鑑定レポートを生成」ボタンクリック時のページ再実行で:
1. `render_client_input_form()` が `None` を返す（フォームsubmitボタンは押されていないため）
2. `client_data is None` の分岐（line 79-88）に入り、早期リターン
3. AI生成ボタン（line 130）のコードに到達しない
4. さらに、`client_data.concern` が次回再実行時に利用不可能

## 受け入れ条件
- [ ] 「AI鑑定レポートを生成」ボタン押下でAIレポートが正常に生成・表示される
- [ ] 命式算出後の状態がページ再実行後も保持される
- [ ] 既存の命式算出フローに影響がない

## 対象スコープ
- `src/pages/01_reading.py` — ページフロー修正
- `src/config.py` — session_stateキー追加

## スコープ外
- UI デザイン変更
- AI クライアントの修正
- テンプレートの修正
