# 要件定義: advice.md 改善案（第2弾）
- 日付: 2026-03-21
- 関連Issue/PR: advice.md

## 目的
advice.md に記載された3つの改善を実装する。

## バグの症状
2. 新規鑑定ボタン押下後、入力欄の値（名前・悩み等）が前回のまま残る
3. 別タブへ遷移して戻ると、生年月日・出生時間がフォームに残ったまま
4. AI鑑定レポート生成時にAPI接続エラーが頻発する

## 根本原因
- #2/#3: `_clear_reading_state()` がカスタム session_state キーのみクリアし、Streamlit フォームウィジェットの内部状態をリセットしない
- #4: リトライ機構がなく、タイムアウト30秒で一時的エラーにも即失敗する

## 受け入れ条件
- [ ] 新規鑑定ボタンでフォーム全入力欄がリセットされる
- [ ] タブ遷移後に生年月日・出生時間が残らない
- [ ] AI接続の一時エラーに対してリトライが行われる
