# 要件定義: セッション永続化 + サイドバー修正
- 日付: 2026-03-26
- 関連Issue/PR: なし（advice.mdによるフィードバック）

## 目的
1. ブラウザリロード時にログイン状態が失われる問題を解決
2. サイドバー（メニュー）が表示されない問題を根本解決

## 受け入れ条件
- [x] ログイン後にブラウザをリロードしてもログイン状態が維持される
- [x] ログアウト時にセッショントークンが無効化される
- [x] サイドバーがログイン後に正しく表示される
- [x] CSSセレクタがStreamlit 1.55のDOM構造に対応している

## 対象スコープ
- セッション永続化: config.py, models.py, auth_session_repo.py, auth.py, app.py, migration
- サイドバー修正: theme.py, auth.py, app.py（CSSセレクタ全面更新）

## スコープ外
- Cookie方式（st.query_paramsで十分と判断）
- CSRF対策（VPSローカル運用のため）
