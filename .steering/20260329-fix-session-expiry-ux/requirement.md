# 要件定義: セッション切れUX改善
- 日付: 2026-03-29
- 関連Issue/PR: advice.md

## 目的
ログイン中にセッションが突然切れて「ログインが必要です」と表示される問題のUXを改善する。

## バグの症状
- ログイン中に急に画面がログアウトし、「ログインが必要です」という無味乾燥なエラーが表示される
- ユーザーはなぜログアウトされたのか、どうすればいいのかわからない

## 根本原因
1. `_try_restore_from_token()` がセッショントークン復元成功後にURLからトークンを削除している
2. Streamlitの `session_state` が揮発した際（WebSocket再接続、スリープ復帰等）、URLにトークンが残っていないため復元手段がない
3. `require_page_auth()` が `st.error("ログインが必要です。")` を表示するだけで、ユーザーへの誘導がない

## 受け入れ条件
- [ ] session_state揮発時にセッショントークンから自動復元できる
- [ ] トークン期限切れ時はフレンドリーなメッセージが表示される
- [ ] ユーザーがログインページへ遷移する手段が提供される
- [ ] セキュリティ（Referer漏洩防止）が維持される
- [ ] 既存テストが全て通る

## 対象スコープ
- `src/utils/auth.py` — セッション管理ロジック

## スコープ外
- セッション有効期限の変更
- Cookie ベースのセッション管理への移行
