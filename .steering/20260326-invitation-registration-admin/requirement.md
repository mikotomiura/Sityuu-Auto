# 要件定義: 招待リンクによるWebユーザー登録 + 管理者ページ
- 日付: 2026-03-26
- 関連Issue/PR: advice.md

## 目的
ユーザー登録手段をCLI（scripts/create_user.py）のみから、Webベースの招待リンク方式に拡張する。
また、adminロールを活用した管理者ページを新設し、ユーザー管理をWeb UIで完結可能にする。

## 受け入れ条件
- [ ] 管理者が招待リンク（ワンタイムトークン付きURL）を生成できる
- [ ] 招待リンクからアクセスしたユーザーが、ユーザー名とパスワードを設定して登録できる
- [ ] 使用済みトークンは再利用不可
- [ ] 有効期限切れトークンは登録不可
- [ ] 管理者ページでユーザー一覧を表示できる
- [ ] 管理者ページで招待リンク一覧を表示・生成できる
- [ ] 管理者ページでユーザーを削除できる
- [ ] adminロール以外のユーザーには管理者ページが表示されない

## 対象スコープ
- DB: invitation_tokens テーブル追加（マイグレーション）
- DB: InvitationRepository 新規作成
- DB: UserRepository に find_all / delete 追加
- UI: auth.py にセルフ登録フォーム追加（トークン検証付き）
- UI: pages/05_admin.py 新規作成
- UI: app.py にadminページのナビゲーション追加（ロール条件付き）

## スコープ外
- パスワードリセット機能
- 2要素認証（2FA）
- メール送信による招待通知
- ロールの細分化（admin/user以外）
