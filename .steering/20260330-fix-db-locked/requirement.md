# 要件定義: SQLite "database is locked" 根本解決
- 日付: 2026-03-30
- 関連: advice.md (Bug 2, 3, 4)

## 目的
全DB書き込み操作が `database is locked` で失敗する問題を解消する。

## 再現エラーログ（VPS）
```
2026-03-30 01:48:03 [ERROR] 相談者の保存に失敗: database is locked
2026-03-30 01:49:00 [ERROR] メールアドレス更新失敗: database is locked
2026-03-30 01:49:58 [ERROR] セッショントークン作成失敗: database is locked
2026-03-30 01:50:12 [ERROR] 期限切れリセットトークン削除失敗: database is locked
2026-03-30 01:50:19 [ERROR] 招待トークン削除失敗: database is locked
```

## 根本原因
1. `sqlite3.connect()` の `timeout` パラメータ未指定（デフォルト5秒）
2. スレッド間でDB書き込み競合が発生した際、5秒では不十分
3. 未コミットトランザクションがコネクション再利用時に残留し、ロックを保持し続ける可能性

## 受け入れ条件
- [ ] DB書き込み操作（メール保存・鑑定保存・トークン削除）が正常に動作する
- [ ] 未コミットトランザクションの残留が防止される
- [ ] WALモードが有効であることがログで確認できる
