# バグ修正: ユーザーAPI設定がDB永続化されない
- 日付: 2026-03-23

## 症状
1. ユーザーが設定ページでAPIプロバイダー/モデルを変更しても、ログアウト→再ログインするとデフォルト（gemini/gemini-2.5-flash）にリセットされる
2. usersテーブルに preferred_provider / preferred_model カラムが存在するが、アプリケーションから読み書きされていない
3. 初回ログイン時にAPIキー設定を促すガイドがない

## 根本原因
- API設定が st.session_state（揮発性）にのみ保存されている
- UserRepository に preferences の読み書きメソッドがない
- ログイン時にユーザーの保存済み設定を session_state に復元する処理がない

## 期待される修正後の動作
1. API設定変更時にDBに永続化される
2. 再ログイン時にDBから設定が復元される
3. APIキー未登録のユーザーに設定を促すガイドが表示される
