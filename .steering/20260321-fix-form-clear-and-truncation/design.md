# 設計メモ: フォームクリア不具合 & AI出力途切れ修正

- 日付: 2026-03-21

## 根本原因

### Bug #2 & #3: フォームクリア不具合
- `_clear_reading_state()` は `form_version` をインクリメントしてフォームキーを変更するが、
  `st.date_input` と `st.time_input` は Streamlit の session_state にウィジェット固有のキーで値を保持する
- Bug #3 はそもそもクリア処理が呼ばれない（タブ遷移時に状態リセットのトリガーがない）

### Bug #4: AI出力途切れ
- `API_MAX_TOKENS = 2000` が鑑定レポートの長さに対して不足

## 修正方針

### Bug #2 & #3
1. 鑑定結果が存在する場合、入力フォームを非表示にし、結果表示 + 「新規鑑定を開始」ボタンのみ表示
2. `_clear_reading_state()` で form_version インクリメントにより新しいフォームを生成（既存の仕組みで十分）
3. タブ遷移後に戻った場合も、鑑定完了状態なら結果のみ表示

### Bug #4
- `API_MAX_TOKENS` を 2000 → 4096 に増加
