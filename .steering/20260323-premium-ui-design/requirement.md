# 要件定義: プレミアムUI/UXデザインの注入
- 日付: 2026-03-23
- 関連Issue/PR: advice.md 項目6

## 目的
占い・四柱推命アプリにふさわしい神秘的で高級感のあるカスタムCSSを全ページに適用し、Streamlitのデフォルトデザインを脱却する。

## 受け入れ条件
- [ ] ミッドナイトブルー・深紫を基調とした配色が全ページに適用されている
- [ ] ゴールド・シルバーのアクセントカラーが見出し・ボタンに使用されている
- [ ] ボタンにホバーエフェクトが実装されている
- [ ] 入力フォームが角丸化されている
- [ ] カード風レイアウトにシャドウ効果が付与されている
- [ ] 既存の機能・操作に影響を与えていない

## 対象スコープ
- `src/components/theme.py` — 新規作成（カスタムCSS注入）
- `src/app.py` — テーマ適用の呼び出し追加

## スコープ外
- 認証システム（advice.md 項目1-5）— プロジェクト方針「SaaS化しない」と矛盾するため対象外
- ページ個別のレイアウト変更
- JavaScript によるインタラクション追加
