# 要件定義: セキュリティ強化（ネットワーク露出・トークン漏洩対策）

- 日付: 2026-03-29
- 関連Issue/PR: advice.md

## 目的

セキュリティ検査で発見された脆弱性を修正し、商用運用に耐えるセキュリティ態勢を確立する。

## 受け入れ条件

- [ ] server.address を 127.0.0.1 に変更（ローカルファースト原則）
- [ ] セッショントークンのURL露出を最小化
- [ ] XSRF/CORS設定を明示化
- [ ] 招待リンクのパラメータ名ハードコードを修正
- [ ] 既存テスト全通過

## 対象スコープ

- .streamlit/config.toml
- src/utils/auth.py
- src/pages/05_admin.py

## スコープ外

- HTTPS導入（インフラ層の対応）
- Cookie方式へのセッション管理変更（大規模な設計変更が必要）
