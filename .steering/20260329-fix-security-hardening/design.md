# 設計メモ: セキュリティ強化

- 日付: 2026-03-29

## 実装アプローチ

### 1. ネットワーク露出の修正
- config.toml の address を 127.0.0.1 に変更
- VPS運用時はNginxリバースプロキシ経由を前提とする

### 2. セッショントークンのURL露出最小化
- ログイン成功・トークン復元後に即座にURLからトークンを削除
- session_stateにトークンを保持し、リロード時はst.query_paramsが空でもsession_stateで復元を試みる
- トークンはログイン処理完了直後にURLから消去する（Referer漏洩防止）

### 3. XSRF/CORS設定の明示化
- config.toml にデフォルト値をコメント付きで明記

### 4. 招待リンクのハードコード修正
- 05_admin.py の表示部で定数を使用

## 影響範囲

- セッション復元フロー（トークン削除タイミングの変更）
- VPS運用時のポートバインド
