# 要件定義: advice.md 記載の3バグ修正
- 日付: 2026-03-30
- 関連: advice.md

## 目的
ユーザーフィードバック（advice.md）に記載された3つのバグを修正する。

## バグ一覧

### Bug 1: セッション永続化の問題
- **症状:** 数分程度の利用でもリロードするとログイン画面に遷移する
- **根本原因:** `require_page_auth()` が session_state 消失時にトークン復元を試行せず、警告のみ表示
- **修正:** require_page_auth でトークン復元を試行 + トークンTTLリフレッシュ追加

### Bug 2: 設定ページのフィードバックUI不統一
- **症状:** メールアドレス保存等で「保存が完了しました」のフィードバックが表示されない
- **根本原因:** `st.success()` の直後に `st.rerun()` を呼ぶため、成功メッセージが描画前に消失
- **修正:** session_state フラグ方式で rerun 後も成功メッセージを表示

### Bug 3: 鑑定結果の保存失敗 + 矛盾メッセージ（最重要）
- **症状:** 「保存に失敗しました」と「鑑定結果は自動的に保存されました」が同時表示。データ未保存。
- **根本原因:** `_save_session_to_db()` が DatabaseError を内部で握りつぶし、呼び出し元が無条件で SESSION_KEY_SESSION_SAVED=True に設定
- **修正:** 関数の戻り値で成否を伝達 + 失敗時の再保存UIを追加
