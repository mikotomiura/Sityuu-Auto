# 要件定義: 鑑定履歴閲覧ページ
- 日付: 2026-03-20
- 関連Issue/PR: F-009（鑑定履歴一覧）、F-010（鑑定履歴詳細）

## 目的
過去の鑑定履歴をアプリ上で一覧表示・詳細閲覧できるページを実装し、
メンターがリピーターの過去セッションを振り返れるようにする。

## 受け入れ条件
- [ ] 鑑定履歴の一覧が日付降順で表示される
- [ ] 相談者名・日付での検索/フィルタができる
- [ ] 一覧から選択して鑑定詳細（命式・AIレポート・傾聴ヒント）を閲覧できる
- [ ] 詳細画面からMDエクスポートができる
- [ ] テストが通過する
