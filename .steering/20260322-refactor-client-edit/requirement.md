# 要件定義: 相談者情報の全フィールド編集対応
- 日付: 2026-03-22
- 関連Issue/PR:

## 目的
相談者管理の詳細画面で、現在フリガナとメモしか編集できない状態を改善し、
名前・生年月日・出生時間・性別を含む全フィールドを編集可能にする。

## 受け入れ条件
- [ ] リポジトリ層: update() が birth_date, birth_time, gender を受け付ける
- [ ] UI層: 詳細画面で名前・生年月日・出生時間・性別・フリガナ・メモすべて編集可能
- [ ] テスト: 新パラメータの更新テストが通過する
- [ ] 既存テストが全て通過する

## 対象スコープ
- `src/db_service/repositories/client_repo.py` — update メソッド拡張
- `src/pages/03_clients.py` — 詳細ビューの編集フォーム拡張
- `tests/integration/test_db_operations.py` — テスト追加

## スコープ外
- 相談者の削除機能
- 生年月日変更時の命式再計算（既存セッションへの遡及適用）
