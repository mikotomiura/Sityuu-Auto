# 要件定義: 相談者情報の変更が保存されないバグ修正
- 日付: 2026-03-22
- 関連Issue/PR:

## バグの症状
相談者管理の詳細画面で情報を変更し「変更を保存」ボタンを押すと、
「変更はありません。」と表示され、変更が反映されない。

## 再現手順
1. 相談者管理ページで相談者の「詳細」を開く
2. 名前やフリガナ等のフィールドを変更する
3. 「変更を保存」ボタンをクリックする
4. 「変更はありません。」と表示される

## 根本原因
Streamlit の `st.text_input` / `st.date_input` 等を `st.form` なしで使用しているため、
ウィジェットの値変更とボタンクリックが同時に発生した際にタイミング問題が発生する。

具体的には:
- `st.form` を使わない場合、各ウィジェットの値変更で個別にrerunが発生する
- ボタンクリック時のrerunでは、変更中のウィジェット値が正しくキャプチャされないことがある
- `st.form` を使えば、submit時に全ウィジェットの値が一括送信されるため確実

## 期待される修正後の動作
- 変更を行い「変更を保存」を押すと正しく変更が検出・保存される
- 変更なしの場合は従来通り「変更はありません。」と表示される

## 対象スコープ
- `src/pages/03_clients.py` — 編集セクションを `st.form` で囲む
